# 产品简报：AI 分身

> 状态：草稿，待确认
> 最后更新：2026-10-08

## 一句话

一个以你为原型的 AI 分身：帮你想方案、做决定、陪你思考，并按你的口吻起草回复。它越用越像你，越用越强。

## 愿景

- **近期**：先为你自己做成，你是唯一的用户。
- **长期**：开放给每个人，让人人都能拥有一个属于自己的 AI 分身。

## 核心场景

| 场景 | 你怎么用 | 它怎么做 |
|---|---|---|
| 陪我思考 | 把纠结的事说给它听 | 用你习惯的方式追问、梳理，帮你看清自己真正在意什么 |
| 想方案 | 抛出一个问题或目标 | 按你的方法论给出方案，并说明"我认为你会这样做，因为……" |
| 做决定 | 列出几个选项 | 按你的原则分析利弊、给出建议，标明是哪条原则在起作用 |
| 替我回复 | 贴入对方发来的消息 | 结合你和这个人的关系、你的说话风格起草回复；**由你修改后自己发送** |

## "像你"的四个维度

1. **记忆**：你经历过什么、懂什么、最近在忙什么。
2. **风格**：你说话、写字的习惯，对不同的人语气也不一样。
3. **判断**：你的价值观、做决定的原则、做产品的方法论。
4. **关系**：你生活和工作中的重要人物，以及你和每个人的相处方式。

这些内容都存成**你能读、能改、能删的文档**（"自我档案"），不藏在模型的黑盒里。

## 数据来源

- **微信聊天记录**（主要来源）：学习你的说话风格、人物关系和判断方式。
- **访谈**（弥补没有日记）：它分几次问你的经历、价值观和做决定的方式。
- **日常纠正**：你说"我不会这么想 / 这么说"，它就更新档案。

## 成长机制

- **纠正即学习**：每次纠正都会写回自我档案。
- **对话后提炼**：每次对话结束，它提出"我新了解到你……"，你确认后才写入档案。
- **盲测**：定期拿你真实回答过的问题考它，你给打分，分数的变化就是它的成长曲线。

## 衡量指标

| 指标 | 含义 |
|---|---|
| 盲测相似度 | 它的回答像不像你，你打 1～5 分 |
| 回复可用率 | 起草的回复中，不改或只小改就能发出去的比例 |
| 建议采纳率 | 方案和决策建议被你采纳的比例 |

## 第一版范围（MVP）

**做：**

- 导入微信聊天记录（文本），自动生成第一版自我档案和人物关系
- 访谈模式，补全档案
- 对话：思考 / 方案 / 决定三种模式
- 回复起草
- 查看和编辑自我档案
- 盲测打分

**暂时不做：**

- 自动发送消息
- 语音、手机 App
- 多用户（给别人用）
- 主动学习外部资讯

## 隐私与安全原则

1. **聊天记录和自我档案永远不进 Git 仓库**（本仓库是公开的）。
2. 发给大模型之前，去掉手机号、证件号、地址、银行卡号等敏感信息。
3. 聊天里有别人说的话：只用于理解你和这个人的关系，不对外展示；可以一键删除某个人的全部数据。
4. **不自动发送任何消息，不接入微信自动化工具**：违反微信规则可能导致封号，而且替你说话必须经过你确认。
5. 可以一键删除全部数据。

## 微信聊天记录怎么导出

微信没有官方的"导出为文本"功能，有两条路：

| 方式 | 做法 | 优点 | 风险 |
|---|---|---|---|
| **手动挑选（推荐起步）** | 在电脑版微信里挑 5～10 段有代表性的聊天（工作、好友、家人），复制文字存成文本文件 | 安全，不碰任何第三方工具 | 费时，量有限 |
| 第三方导出工具 | 用工具解密电脑上的微信数据库，一次导出全部 | 量大、完整 | 非官方，可能违反微信规则；要把全部聊天记录交给第三方程序，有泄露风险；部分工具已下架 |

第一版不需要全部历史记录，**挑选几段有代表性的聊天就够起步**，质量比数量重要。
